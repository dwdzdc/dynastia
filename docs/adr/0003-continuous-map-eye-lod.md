# Jedna ciągła mapa i LOD sterowany okiem

Świat MVP to jedna ciągła, chodzona mapa (wieś → las → droga → miasteczko) o skompresowanych odległościach, w duchu Cultures: miejsca są fizyczne i minimalnie abstrakcyjne. Focus wyznacza „oko" gracza — ślad kamery plus obecność członków rdzenia; poza okiem teren jest we mgle wojny i leży w agregacie, a powrót oka wyzwala deterministyczny catch-up i pop-in LOD 0. Opcja odrzucona: miasteczko off-map jako abstrakcyjny targ/UI (wstępne założenie autora planu) — odrzucona, bo zwiększa abstrakcyjność miejsc, czego projekt celowo unika.
